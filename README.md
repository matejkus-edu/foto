# Fotografie v praxi

Interaktivní cvičení k fotografii pro výuku filmové a audiovizuální výchovy.

- `index.html` – úvodní menu
- `expozice.html` – expoziční trojúhelník (čas závěrky, clona, ISO)
- `kompozice.html` – kompozice snímku a filmové plány
- `kamera.html` – kamera a záběr (plány, rakurz, rovina, formát)

Vše jsou statické soubory bez závislostí. Stačí zapnout GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).
